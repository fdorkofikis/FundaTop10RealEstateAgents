Top 10 Real Estate Agents
Assessment for Funda


Requirements
Determine which makelaars in Amsterdam have the most objects listed for sale.
Make a table of the top 10.
Then do the same thing, but only for objects with a tuin that are listed for sale.


Prerequisites
.NET 9.0
SQL Server
How to run
The Swagger package has been added for a UI of the exposed OpenAPI and can be reached at baseUrl/Scalar.
AI
The solution was written with Rider, with Copilot enabled (GPT-4.1).
I asked Copilot to write the tests for me, but most were missing the point and were rewritten, with one exception that has been commented in the code.
That said, the integration is seamless, so I have some uncertainty whether autocomplete used was from IntelliSense or Copilot integration.
(For example, the LINQ used to order, select the top 10 makelaars, and map them was autocompleted, and it is a little too smart for IntelliSense.)
